# 🌐 BiLIngual - Language Translator App

This is a bilingual language translator web app built using **NLP** and **transformers**. It allows users to input text in one language and get an accurate translation in another language using deep learning models.

---

## 🚀 Features

- 🔤 Translate between multiple languages
- 🧠 Uses transformer-based NLP models
- 📦 Flask backend
- 💻 Clean UI with HTML/CSS
- 🌍 Great for multilingual users and learners

---

## 🛠️ Tech Stack

- Python
- Flask
- Hugging Face Transformers
- HTML/CSS
- Jupyter Notebooks (for model building)
